# BYTE 1.0 checklist (on your Mac)

Try these on the newest version (Settings → About shows it). Each takes a minute or two. Note anything that's
wrong, slow or confusing — a screenshot or the exact message helps most.

## Updates
1. ☐ **One-click update:** Settings → About → **Check for updates** → **Install … and restart**. BYTE comes back on
   the new version.

## The basics
2. ☐ **First answer:** ask "What's a good weeknight dinner with chicken?" It answers in a few seconds.
3. ☐ **Web with sources:** ask "What's the latest news about Apple?" You see sources you can click.
4. ☐ **Deep:** switch to 🔭 Deep and ask something with two sides, e.g. "Is a heat pump worth it in Pittsburgh?"
5. ☐ **A file:** drop a PDF into the chat and ask "What does this say about …?"

## Documents (beta)
6. ☐ **PDF:** Documents → PDF report → "A one-page plan to save $5,000 in a year" → Plan it → Write it → Save as PDF.
7. ☐ **PowerPoint (beta):** same with Slides. Open it in Keynote or PowerPoint and note what looks wrong.

## Voice
8. ☐ **Dictation:** click 🎤 (first time: download the speech model), say a question.
9. ☐ **Hey BYTE** (Settings → Models → Voice → Listen for "Hey BYTE"): say "Hey BYTE, what time is it?"

## Your Mac
10. ☐ **Reminder:** "Remind me to call Mom tomorrow at 3pm" → **Do it** → it's in Reminders → **Undo** removes it.
11. ☐ **Storage:** "What's taking up space on my Mac?"

## Privacy
12. ☐ **Offline:** Settings → Privacy → Work offline. A news question says it's offline; a normal question still works.
13. ☐ **Touch ID lock:** turn it on, then ⌘K → Lock BYTE now → unlock with Touch ID.
14. ☐ **Kids mode:** turn it on with a PIN, ask a kid question, then leave with the PIN. (With an uncensored model in
    use, kids mode refuses to start: that's expected.)
15. ☐ **Backup:** Settings → Privacy → Back up now (with a passphrase). The file appears in iCloud Drive → BYTE Backups.

## How it runs
16. ☐ **Memory:** with BYTE answering, open Activity Monitor → Memory. Note "Memory Pressure" (green is good) and
    BYTE's numbers.
17. ☐ **Quit and reopen:** BYTE opens quickly and your chats are there.

When these pass (or the problems are fixed), BYTE becomes **v1.0.0**.
