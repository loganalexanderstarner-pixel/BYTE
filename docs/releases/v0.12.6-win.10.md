# Windows test build 10: PC control that plans, research in real tabs, jobs, helpers and more (v0.12.6-win.10)

**A test build of BYTE for Windows 10 and 11.** It is not the finished app: expect rough edges and tell us what you find. The Mac app is the same as v0.12.6.

## Installing
1. Download `BYTE_0.12.6-win.10_x64-setup.exe` below (about 560 MB; it carries every engine).
2. Run it. Windows will say it "protected your PC" because the build is not signed with a paid certificate: choose **More info**, then **Run anyway**. It installs for you only, with no administrator rights. If you already have a test build, **uninstall it once first**: this build is signed with BYTE's own update key, so an older test build cannot update to it.
3. Open BYTE.

## What changed in PC control (try these first)
- **"Open Microsoft Edge to YouTube", "go to reddit", "search for …"** now work by exact rules, with no model needed, so they are fast.
- **Free-form requests** ("open Notepad and type hello") are planned from the screen and run step by step, with a card to approve them.
- **If PC control is off**, BYTE now says so and how to turn it on (Settings → Control and screen), instead of saying it cannot control a computer.
- **A model that is too small** is called out, with the recommended one to download. PC control and guided help need a model of about 4B or more: Settings → Models → "PC control" filter → **Use for PC control**.
- **Approval cards** scroll into view, and there is an **Approve and don't ask again** button (listed, and removable, under Settings → Control and screen).

## New
- **Research until I'm back**, in real Edge tabs you watch open (Settings → Control and screen). Say "I'm back" for the summary.
- **Autonomous mode**: give a job in plain words, set what it may do, watch it in a small live window, stop with Ctrl+Alt+F12. A morning report when it ends.
- **Connectors** (your own bots, off by default): Discord, Telegram, Slack, email drafts; **scheduled jobs and triggers**; a morning digest.
- **Everyday helpers**: select a region of the screen and ask about it, "Explain this" at the cursor, an error-dialog helper, smart paste, dictate anywhere, fix my writing in place, Explorer right-click "Ask BYTE", page tools, read aloud, live captions, a meeting assistant, focus mode, Downloads tidy-up.
- **Foundations**: first-run setup, safe mode, crash recovery, "what's new", laptop (battery) mode, a shared never-touch list, an on-screen approval popup, a plain-language privacy page.
- Everything listed here is **off until you turn it on**, and each person's settings, tokens and bots stay on their own PC.

## Help us find problems
- **Hey BYTE not answering?** Settings → Voice and Hey BYTE → turn on **Test log**, say "Hey BYTE" a few times, then Settings → Backup and help → **Prepare a report** and send it to us. The report shows what BYTE heard and whether it took it as the wake phrase.
- Anything else: **Prepare a report** from the same place, with a line about what you tried.
