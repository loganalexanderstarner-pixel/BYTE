# Phase 12 improvements — One-click updates and Homebrew (v0.12.3)

**BYTE v0.12.3** updates itself. It's the last version you install by hand: from now on BYTE tells you when a new
version is out and installs it in one click. It includes v0.12.2 (your own themes, smoother motion, Reduce motion, chimes and VoiceOver checks), which has no separate download, and everything before it. See all versions in [docs/VERSIONS.md](https://github.com/loganalexanderstarner-pixel/BYTE/blob/claude/new-session-tu1a5x/docs/VERSIONS.md).

## New in this version
- **One-click updates** (Settings → About → Updates):
  - BYTE checks once a day and shows "BYTE 0.12.4 is out" when there's a new version;
  - **Install** downloads it, checks that it's really from BYTE's maker (a digital signature), installs it and
    restarts;
  - an update that isn't signed with BYTE's key is refused;
  - turn the daily check off any time. The offline switch and kids mode block updates too.
- **Install with Homebrew:**
  ```
  brew tap loganalexanderstarner-pixel/byte https://github.com/loganalexanderstarner-pixel/BYTE
  brew install --cask byte
  ```
  This also skips the "Open Anyway" step.
- **A new README** that describes everything BYTE does today.

## What BYTE can do in this version
- **Chat on your Mac** or with **BYTE Cloud** (invite only), with cards, on many kinds of models.
- **Research**, **writing and learning**, **speed and tuning**, **memory**, **your files and photos**, **documents**.
- **Mac control** and **Mac upkeep**.
- **Everyday helpers:** tasks and schedules, feeds and watchers, automations and Shortcuts, trackers, connectors and
  dashboards.
- **Windows, keys and voice:** Quick Ask, the menu-bar icon, the command palette, voice input, spoken answers,
  “Hey BYTE”, 2,000+ natural voices, notes, a web clipper, mind maps, a brainstorm board, personality and help.
- **Privacy:** an offline switch, a Touch ID lock, an activity log, kids mode, encrypted backups and erasing.
- **Looks:** 20 themes plus your own, smooth motion, and VoiceOver-friendly controls.
- **Updates:** one click, signed.
