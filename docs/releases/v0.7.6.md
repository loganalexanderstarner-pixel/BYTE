# Phase 7 — Custom assistants (v0.7.6)

**BYTE v0.7.6** lets you set BYTE up for the jobs you do again and again. It has everything from v0.7.5 too. See all
versions in [docs/VERSIONS.md](https://github.com/loganalexanderstarner-pixel/BYTE/blob/claude/new-session-tu1a5x/docs/VERSIONS.md).

## New in this version
- **Assistants** (🤖 in the top bar).
  - An assistant is BYTE with your instructions for one job: how to answer, your level, the style you like, what to
    always or never do. It also has up to four starter prompts and a default mode.
  - Start from a preset (**Email helper**, **Study coach**, **Coding buddy**, **Fitness planner**) and change it, or
    write your own.
  - Press **Chat**: the new chat shows the assistant and its starters, and every answer in it follows its
    instructions.

## What BYTE can do in this version
- **Chat on your Mac** or with **BYTE Cloud** (invite only), with cards, on many kinds of models.
- **Research (Phase 6)**: web search, deep research, fact-checks, comparisons, places, trips, recipes, YouTube, a
  web agent, reviews, prices, game hints.
- **Study and writing (Phase 7)**: flashcards, quizzes, tutor mode, the writing studio, translation, job search,
  custom assistants.
- **Memory**, **your files and photos**, **documents** (PDF, PowerPoint, Word).

## Not in this version yet
The long-form writer, style cloning and poetry/speeches (v0.7.7, the rest of Phase 7), a tuning panel (v0.8),
controlling Mac apps (v0.9), automations (v0.10), voice and quick-ask windows (v0.11), Touch ID and polish (v0.12).
Assistants work on this Mac for now; in Cloud mode the cloud doesn't get the assistant's instructions yet.
