# Phase 7 improvements — Better cards from any model (v0.7.3)

**BYTE v0.7.3** helps small models do better: BYTE checks their cards and fixes obvious mistakes, and a photo
helper lets models that can't see images still answer about your photos. It has everything from v0.7.2 too. See
all versions in [docs/VERSIONS.md](https://github.com/loganalexanderstarner-pixel/BYTE/blob/claude/new-session-tu1a5x/docs/VERSIONS.md).

## New in this version
- **Card checks for small models.** When a small model makes a card, BYTE looks for obvious problems:
  - flashcards whose front just repeats the topic;
  - a recipe for a different dish than you asked for;
  - the same dinner every night;
  - comparison scores that are all the same;
  - missing trip days.

  If it finds one, it asks the model to fix just that and keeps the fix only if it's better. Bigger models aren't
  slowed down.
- **Photo helper.** If the model you use can't see images, a small model that can (a 740 MB download: Settings →
  About → Features → Photo helper) looks at your photo and describes it, so you can still ask "what is this?" or
  "what does this sign say?". It runs only while it's needed.

## What BYTE can do in this version
- **Chat on your Mac** or with **BYTE Cloud** (invite only), with the same cards in both, on many kinds of models.
- **Research (Phase 6)**: web search, deep research, fact-checks, comparisons, places, trips, recipes, YouTube, a
  web agent, reviews, prices, game hints.
- **Study (Phase 7)**: flashcards with spaced repetition, quizzes, tutor mode.
- **Memory**, **your files and photos**, **documents** (PDF, PowerPoint, Word).

## Not in this version yet
A hint when your Mac could run a better model, the writing studio (v0.7.4), translate, a job tracker and custom
assistants (later v0.7.x), a tuning panel (v0.8), controlling Mac apps (v0.9), automations (v0.10), voice and
quick-ask windows (v0.11), Touch ID and polish (v0.12).
