# Windows test build 15: one answer, not two (v0.12.6-win.15)

**A test build of BYTE for Windows 10 and 11.** Not the finished app: tell us what you find. The Mac app is the same as v0.12.6.

## Installing
Download `BYTE_0.12.6-win.15_x64-setup.exe` below and run it. Windows will say it "protected your PC": choose **More info**, then **Run anyway**. It updates the previous test build in place.

## Changed since build 14
- **Hey BYTE no longer answers twice.** Every BYTE window heard the question and each one asked and spoke the answer, so two voices competed (that was a big part of the slowness). Only the window that was sent the question acts now.
- **The start of your question is no longer lost.** Words said right after "Hey BYTE", while BYTE was still checking the phrase, are kept.
- **Quicker speech-to-text on this PC** for short questions (a two-second question took up to 20 seconds with the big model).
- **Talking over BYTE:** the echo canceller could run away and then never hear you; it now resets itself.
- Details that make testing without a microphone possible (nothing changes for normal use).
