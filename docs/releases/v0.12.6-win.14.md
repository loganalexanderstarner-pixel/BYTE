# Windows test build 14: talk over BYTE, the quick Hey BYTE detector (v0.12.6-win.14)

**A test build of BYTE for Windows 10 and 11.** Not the finished app: tell us what you find. The Mac app is the same as v0.12.6.

## Installing
Download `BYTE_0.12.6-win.14_x64-setup.exe` below and run it. Windows will say it "protected your PC": choose **More info**, then **Run anyway**. It updates the previous test build in place.

## Changed since build 13
- **Talking over BYTE on speakers:** BYTE now removes its own voice from the microphone using a copy of what the speakers play, so you can interrupt it, or say "Hey BYTE" while it talks. A filter that went wrong in build 13 (which stopped interrupting from ever working) now resets itself.
- **After BYTE answers**, one short follow-up is heard without saying "Hey BYTE", then it stops listening (Settings → Voice: After BYTE answers Hey BYTE).
- **A tiny built-in Hey BYTE detector** (Settings → Voice: Quick or Careful; Careful is the default for now).
- "Never ask" now also skips the first-time "Let BYTE use this program?" card.
- Opening Edge, Chrome and other programs by name, and web searches, work in more phrasings.
- No more re-download of the small speech model when it is already installed.
