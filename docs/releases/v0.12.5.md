# Phase 12 improvements — Texting in plain words, and updates that explain themselves (v0.12.5)

**BYTE v0.12.5** fixes what was found while testing v0.12.4. See all versions in [docs/VERSIONS.md](https://github.com/loganalexanderstarner-pixel/BYTE/blob/claude/new-session-tu1a5x/docs/VERSIONS.md).

## New in this version
- **Text someone the way you'd say it:** "text Mom I'm on my way" now opens Messages with the text filled in (you
  press Send). It used to need a word like "saying". A name, "my wife", a phone number or an email all work.
- **BYTE no longer says it "can't send texts".** With Mac control on, it knows what it can do in your apps.
- **Updates explain what's wrong:** if macOS is running BYTE from a read-only place (the .dmg window, or a hidden
  copy because it was downloaded), BYTE says how to fix it instead of "Read-only file system". The fix, once:
  quit BYTE, make sure it's in Applications, run `xattr -cr /Applications/BYTE.app` in Terminal, open it again.
- **Update notes read cleanly** in Settings → About.
- **The microphone works:** BYTE now asks macOS for the microphone (voice input, Talk mode, "Hey BYTE") and shows
  up in System Settings → Microphone. Before, macOS refused it silently. Mac control's permission is declared the
  same way.

## What BYTE can do in this version
Everything in v0.12.4: chat on your Mac or BYTE Cloud, research, writing and learning, documents (beta), your
files, Mac control, upkeep, everyday helpers, voice, notes, privacy, 20 themes plus your own, and signed one-click
updates.
