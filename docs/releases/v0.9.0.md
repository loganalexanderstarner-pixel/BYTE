# Phase 9 — BYTE uses your Mac's apps (v0.9.0)

**BYTE v0.9.0** starts Phase 9: ask BYTE and it adds reminders, notes and calendar events, reads your schedule,
plays music and changes settings on your Mac. It asks before adding or changing anything, and you can undo what it
added. It has everything from v0.8.0 too. See all versions in
[docs/VERSIONS.md](https://github.com/loganalexanderstarner-pixel/BYTE/blob/claude/new-session-tu1a5x/docs/VERSIONS.md).

## New in this version
- **Reminders**: "Remind me to call Mom tomorrow at 3pm", "add milk to my reminders", "what are my reminders?"
- **Calendar**: "Add lunch with Sam to my calendar Friday at 1pm for 90 minutes", "what's on my calendar this week?"
- **Notes**: "Make a note: gate code 4417", "save this to notes" (saves BYTE's last answer), "find my notes about
  the lease".
- **Music**: "play some jazz", "pause the music", "next song", "what's playing?"
- **Your Mac**: dark mode on or off, volume ("set the volume to 30"), mute, Wi-Fi on or off, turn the display off,
  and "open Bluetooth settings" (or Battery, Displays, Privacy & Security…).
- **Shortcuts**: "list my shortcuts", "run my Morning shortcut".
- **Safari**: "what's this tab in Safari about?"
- **Safe by design**:
  - Before adding a note, reminder or event, running a shortcut or turning Wi-Fi off, BYTE shows exactly what it
    will do and waits for **Do it**.
  - Notes, reminders and events it added have an **Undo** button.
  - BYTE only runs a fixed set of actions. What you type is passed to them as plain text, so it can never be run as
    a command.
- The first time BYTE uses an app, macOS asks "BYTE wants to control Notes": click **OK**. If you clicked Don't
  Allow, BYTE tells you where to turn it back on (System Settings → Privacy & Security → Automation).
- Switch it off in Settings → About → Features → **Mac control**.

## What BYTE can do in this version
- **Chat on your Mac** or with **BYTE Cloud** (invite only), with cards, on many kinds of models, with speed boost,
  per-Mac tuning, a model lab and battery saver.
- **Research (Phase 6)**, **writing and learning (Phase 7)**, **memory**, **your files and photos**, **documents**.
- **Mac control (Phase 9, part 1)**: Reminders, Calendar, Notes, Music, Shortcuts, Safari and system settings.

## Not in this version yet
More Mac control is coming in v0.9.x: Mail (read, triage, drafts in your tone), Messages drafts, a hotkey for
selected text anywhere, finding and organizing files, clipboard history, a Finder "Ask BYTE" action and a terminal
helper. Calendar events that repeat may not show when BYTE reads your schedule. Then automations (v0.10), voice and
quick-ask windows (v0.11), Touch ID and polish (v0.12).
