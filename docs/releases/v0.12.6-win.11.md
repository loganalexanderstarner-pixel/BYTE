# Windows test build 11: Hey BYTE, PC control and voice fixes (v0.12.6-win.11)

**A test build of BYTE for Windows 10 and 11.** Not the finished app: tell us what you find. The Mac app is the same as v0.12.6.

## Installing
1. Download `BYTE_0.12.6-win.11_x64-setup.exe` below (about 560 MB).
2. Run it. Windows will say it "protected your PC": choose **More info**, then **Run anyway**. It installs for you only, with no administrator rights, and updates build 10 in place.

## Fixed since build 10
- **"Hey BYTE" is about ten times quicker to notice you.** It used the big speech model for every check (about 3 seconds). BYTE now fetches the small one on its own and the check takes about 0.3 seconds.
- **BYTE waits 15 seconds for your question** after "Hey BYTE" (it was 10).
- **"Never ask, just do it" now also skips the first-time "Let BYTE use this program?" card.** It was the one card that ignored the setting.
- **"Open Microsoft Edge"** (and Chrome, File Explorer, Word, Excel, PowerPoint, Outlook, Task Manager) now open by their everyday names.
- **The cloud voice is brisker** (it sounded slow and drawn out).
- **Approval cards** scroll into view so their buttons are never hidden.

## Help us find problems
- Settings → Voice and Hey BYTE → **Test log** records what Hey BYTE heard, how long it took, what a spoken question was heard as, and why interrupting (talking over BYTE) does or does not trigger. Then Settings → Backup and help → **Prepare a report** and send it to us. It records spoken words, so turn it off afterwards.
- If BYTE does not speak, check **Settings → Voice**: "Read answers aloud" must be on, and the voice location should be BYTE Cloud unless you have installed a voice on this PC.
