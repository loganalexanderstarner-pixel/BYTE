# Phase 7 — Translate and job search (v0.7.5)

**BYTE v0.7.5** translates long texts, files and web pages, and adds a job search tracker that reads postings for
you. It has everything from v0.7.4 too. See all versions in
[docs/VERSIONS.md](https://github.com/loganalexanderstarner-pixel/BYTE/blob/claude/new-session-tu1a5x/docs/VERSIONS.md).

## New in this version
- **Translate.** Ask in the chat:
  - "translate this into Spanish" (the answer above);
  - "translate the attached file to German";
  - "translate https://… to English" (with Web on);
  - "translate 'good morning' to Japanese".

  Long texts are translated part by part, and you see each part as soon as it's done. The writing studio (✍️) has a
  **Translate** button with a language list too.
- **Job search** (💼 in the top bar).
  - Paste a job posting's link and BYTE fills in the company, role, location, pay, deadline and main requirements
    for you to check.
  - Track each job from Saved to Applied, Interviewing and Offer, with notes and a deadline countdown.
  - **Prepare for the interview** asks BYTE, in the chat, what the company does, likely questions with how you could
    answer, and what to ask them.

## What BYTE can do in this version
- **Chat on your Mac** or with **BYTE Cloud** (invite only), with cards, on many kinds of models.
- **Research (Phase 6)**: web search, deep research, fact-checks, comparisons, places, trips, recipes, YouTube, a
  web agent, reviews, prices, game hints.
- **Study and writing (Phase 7)**: flashcards, quizzes, tutor mode, the writing studio, translation, job search.
- **Memory**, **your files and photos**, **documents** (PDF, PowerPoint, Word).

## Not in this version yet
Custom assistants (v0.7.6), a tuning panel (v0.8), controlling Mac apps (v0.9), automations (v0.10), voice and
quick-ask windows (v0.11), Touch ID and polish (v0.12). Very small models (under 1B) translate with mistakes; 1B and
larger do much better.
