# Windows test build 13: timing for spoken turns (v0.12.6-win.13)

**A test build of BYTE for Windows 10 and 11.** Not the finished app: tell us what you find. The Mac app is the same as v0.12.6.

## Installing
Download `BYTE_0.12.6-win.13_x64-setup.exe` below and run it. Windows will say it "protected your PC": choose **More info**, then **Run anyway**. It updates the previous test build in place.

## Changed since build 12
- **The Test log now times every step of a spoken turn:** how long your question was, how long it took to turn it into text, how long the cloud took to start answering, and how long the voice took to produce its first sound. Say "Hey BYTE, what's the weather", then Settings → Backup and help → **Prepare a report**. Turn the Test log off afterwards: it records spoken words.
- Weather and other temperatures are now spoken as plain "degrees" (the cloud voice read "Fahrenheit" as "grand height").
- Everything from builds 11 and 12 is included.
