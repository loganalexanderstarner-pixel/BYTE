# Phase 8 — Model lab, tuning and battery saver (v0.8.0)

**BYTE v0.8.0** completes Phase 8 (Speed). You can now try any model in the GGUF format, fine-tune how each model
answers, and BYTE goes easy on your battery. It has everything from v0.7.7 too. See all versions in
[docs/VERSIONS.md](https://github.com/loganalexanderstarner-pixel/BYTE/blob/claude/new-session-tu1a5x/docs/VERSIONS.md).

## New in this version
- **Model lab** (Settings → Models).
  - Pick a `.gguf` file on your Mac, or paste a Hugging Face link to one.
  - BYTE reads only the file's header, so nothing big is downloaded first. It shows the architecture, size, quantization and
    longest context, and whether the model fits this Mac (and with how much context).
  - **Add to BYTE**: a file on your Mac is used where it is; a link downloads it. Added models appear with the
    others and can be removed any time.
- **Advanced tuning** (Settings → Engine).
  - For the model you're using: temperature, top-p, a thinking budget and extra instructions. Each slider starts
    at that model's recommended value, shown next to it, with a reset button.
  - Live meters: memory used, BYTE's engine, what the GPU can use, and the battery.
- **Battery saver** (on by default): below 20% and unplugged, Deep and Extended answer like Auto and thinking is
  kept short, so answers come faster and use less power. BYTE tells you when it's on.
- Custom assistants now work in **Cloud mode** too.

## What BYTE can do in this version
- **Chat on your Mac** or with **BYTE Cloud** (invite only), with cards, on many kinds of models, with speed boost
  and per-Mac tuning.
- **Research (Phase 6)**: web search, deep research, fact-checks, comparisons, places, trips, recipes, YouTube, a
  web agent, reviews, prices, game hints.
- **Writing and learning (Phase 7)**: flashcards, quizzes, tutor mode, the writing studio, long pieces in your
  style, translation, job search, custom assistants.
- **Memory**, **your files and photos**, **documents** (PDF, PowerPoint, Word).

## Not in this version yet
Controlling Mac apps (v0.9), automations (v0.10), voice and quick-ask windows (v0.11), Touch ID and polish (v0.12).
Models added in the lab don't get speed boost or card quality checks tuned for them yet, and a model whose
architecture this BYTE's engine doesn't know won't load (the lab says so first when it can).
