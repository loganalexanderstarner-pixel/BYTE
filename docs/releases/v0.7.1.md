# Phase 7 improvements — Cards in Cloud mode (v0.7.1)

**BYTE v0.7.1** brings BYTE's cards to Cloud mode and makes tutor mode steadier. It has everything from v0.7.0
too. See all versions in [docs/VERSIONS.md](https://github.com/loganalexanderstarner-pixel/BYTE/blob/claude/new-session-tu1a5x/docs/VERSIONS.md).

## New in this version
- **Cards in Cloud mode**: recipes and meal plans, compare tables, trips, reviews, prices, game hints, YouTube
  summaries, fact-checks, flashcards and quizzes now work when you're chatting with your BYTE cloud, as long as a
  model is loaded on your Mac. BYTE builds the card on your Mac, and your cloud writes the answer from what BYTE
  found. Without a model on your Mac, Cloud mode works as before.
- **Tutor mode** never gives the answer away, even with small models.

## What BYTE can do in this version
- **Chat on your Mac** or with **BYTE Cloud** (invite only), with the same cards in both.
- **Research (Phase 6)**: web search, deep research, fact-checks, comparisons, places, trips, recipes, YouTube, a
  web agent, reviews, prices, game hints.
- **Study (Phase 7)**: flashcards with spaced repetition, quizzes, tutor mode.
- **Memory**, **your files**, **documents** (PDF, PowerPoint, Word).

## Not in this version yet
The writing studio (v0.7.2), translate, a job tracker and custom assistants (later v0.7.x), a tuning panel (v0.8),
controlling Mac apps (v0.9), automations (v0.10), voice and quick-ask windows (v0.11), Touch ID and polish (v0.12).
