# Phase 7 improvements — More models, and cards everywhere (v0.7.2)

**BYTE v0.7.2** makes BYTE's features work with more kinds of models and brings the cards to Cloud mode even when
no model is loaded on your Mac. It has everything from v0.7.1 too. See all versions in
[docs/VERSIONS.md](https://github.com/loganalexanderstarner-pixel/BYTE/blob/claude/new-session-tu1a5x/docs/VERSIONS.md).

## New in this version
- **Works with more models.** BYTE's cards and tools were tested on Gemma, Llama and DeepSeek-R1 as well as Qwen,
  and everything that broke is fixed:
  - Gemma models can now use the calculator, web search and every card.
  - When a model writes a tool request BYTE can't read, BYTE answers without tools instead of failing.
  - Models that always think first, like DeepSeek-R1, get room to think before filling in a card.
- **Cards in Cloud mode without a local model.** Your BYTE cloud fills in the recipe, comparison, trip, flashcard
  or quiz card behind the scenes, in a short "BYTE card helper" chat that BYTE deletes afterwards.
- **Steadier flashcards and quizzes** from small models: no more six cards with the same front, no repeated quiz
  questions, and cut-off replies keep the cards that were finished.
- Chat titles stay short.

## What BYTE can do in this version
- **Chat on your Mac** or with **BYTE Cloud** (invite only), with the same cards in both.
- **Research (Phase 6)**: web search, deep research, fact-checks, comparisons, places, trips, recipes, YouTube, a
  web agent, reviews, prices, game hints.
- **Study (Phase 7)**: flashcards with spaced repetition, quizzes, tutor mode.
- **Memory**, **your files**, **documents** (PDF, PowerPoint, Word).

## Not in this version yet
Quality checks for cards from small models and photo help for models that can't see (v0.7.3), the writing studio
(v0.7.4), translate, a job tracker and custom assistants (later v0.7.x), a tuning panel (v0.8), controlling Mac
apps (v0.9), automations (v0.10), voice and quick-ask windows (v0.11), Touch ID and polish (v0.12).
