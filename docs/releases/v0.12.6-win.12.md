# Windows test build 12: Hey BYTE stops listening after one follow-up (v0.12.6-win.12)

**A test build of BYTE for Windows 10 and 11.** Not the finished app: tell us what you find. The Mac app is the same as v0.12.6.

## Installing
Download `BYTE_0.12.6-win.12_x64-setup.exe` below and run it. Windows will say it "protected your PC": choose **More info**, then **Run anyway**. It updates build 11 in place.

## Changed since build 11
- **Hey BYTE works like a smart speaker:** BYTE answers, listens a few seconds (6) for one follow-up, then stops until you say "Hey BYTE" again. It no longer keeps answering whatever it hears. Settings → Voice and Hey BYTE → **After BYTE answers "Hey BYTE"** lets you pick one short follow-up (default), keep listening until you say "thanks", or no follow-up.
- Everything from build 11 is included: a much quicker wake check, "never ask" skipping the first-time program card, "Open Microsoft Edge" by name, a brisker cloud voice.

## Help us find problems
Settings → Voice and Hey BYTE → **Test log**, try Hey BYTE, a PC command and an interrupt, then Settings → Backup and help → **Prepare a report**. Turn the Test log off afterwards: it records spoken words.
