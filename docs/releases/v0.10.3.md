# Phase 10 improvements — Automations and Shortcuts (v0.10.3)

**BYTE v0.10.3** does routines for you: a few steps one after another, when you ask, on a schedule, or when BYTE
opens. Any of them can become a Shortcut in your menu bar or something you ask Siri for, and BYTE can now open at
login so it's working all day. It has everything from v0.10.2 too. See all versions in
[docs/VERSIONS.md](https://github.com/loganalexanderstarner-pixel/BYTE/blob/claude/new-session-tu1a5x/docs/VERSIONS.md).

## New in this version
- **Automations**: just ask, for example "every weekday at 8am, find the latest AI news, then summarize it in five
  bullets, then save it to a file".
  - BYTE shows the steps on an approval card first. Nothing is saved or run before you say OK.
  - Steps can: ask BYTE anything (with web search, cards and all), write your daily briefing, send you a
    notification, add a to-do, save to a file (Documents → BYTE → Automations), or run one of your Shortcuts.
  - Each step gets the text from the step before, so "summarize it" works on the answer above it.
  - They run when you want: on a schedule, when BYTE opens, or only when you run them.
- **Multi-step requests**: "research the best budget espresso machines, then write a short buying guide from it
  and save it to a file".
  - BYTE does the steps in the background, and a card in the chat shows each one as it goes.
  - The result is saved as a chat, and you get a notification.
  - If a step fails (for example, no model was loaded), BYTE stops there. **Run again from step N** keeps the steps
    that worked.
- **The ✅ panel has an Automations section**: build one step by step (pick each step's kind, reorder, remove),
  run it now, turn it off, edit, or open the last result.
- **Add to Shortcuts** (the link button next to an automation) makes a real Shortcut that starts it:
  - Put it in the menu bar or Dock, or say "Hey Siri, Morning AI news".
  - Each Shortcut carries its own secret key, so a web page can't start your automations.
  - macOS needs you signed in to iCloud to add a shortcut made by an app. If it can't, BYTE shows a link and two
    steps to make it by hand.
- **Open BYTE at login** (Settings → About → In the background) starts BYTE quietly with no window, so schedules,
  watched pages and automations run all day.
- **Keep running when the window is closed** (on by default): closing the window hides BYTE, clicking it in the
  Dock brings it back, and ⌘Q quits.
- When nobody is watching (a schedule or automation), anything that needs your OK is skipped at once instead of
  waiting.
- Switch automations off in Settings → Features → **Automations**.

## What BYTE can do in this version
- **Chat on your Mac** or with **BYTE Cloud** (invite only), with cards, on many kinds of models.
- **Research**, **writing and learning**, **speed and tuning**, **memory**, **your files and photos**, **documents**.
- **Mac control** and **Mac upkeep**: Apple apps, Mail, Messages, selected text, clipboard, files, Terminal, storage
  clean-up, health checks, uninstalling, login items.
- **Tasks and schedules**: to-dos with reminders, a daily briefing, scheduled questions.
- **Feeds and watchers**: news digests, page-change and price alerts.
- **Automations (new)**: routines of steps, multi-step requests, Shortcuts that start them, opening at login.

## Not in this version yet
Trackers (packages, bills and subscriptions, gifts, car and home: v0.10.4), connectors (v0.10.5) and dashboards
(v0.10.6). Steps that need your OK (Mail drafts, Mac changes) are skipped inside automations for now. `byte://`
links and Shortcuts are macOS only.
