# Phase 9 improvements — Selected text anywhere and clipboard history (v0.9.2)

**BYTE v0.9.2** brings BYTE to text in any app: select it, press **⌥⌘B**, and fix, rewrite, translate, answer
or explain it, then put the result straight back. It also adds an optional clipboard history. It has everything from
v0.9.1 too. See all versions in
[docs/VERSIONS.md](https://github.com/loganalexanderstarner-pixel/BYTE/blob/claude/new-session-tu1a5x/docs/VERSIONS.md).

## New in this version
- **⌥⌘B on selected text, in any app** (Mail, Notes, Safari, Word, Slack…).
  - The writing studio opens with that text. Rewrite, Shorten, Expand, Fix grammar, change the tone or translate it,
    or use the two new actions:
    - **Reply**: BYTE writes your answer to a message someone sent you.
    - **Explain**: what it means, in plain words.
  - **Paste into Mail** (or whichever app it came from) puts the result back where your text was.
  - Your clipboard is left as it was.
  - The first time, macOS asks you to allow BYTE in System Settings → Privacy & Security → Accessibility, because
    BYTE presses ⌘C for you.
- **Clipboard history** (📋, off until you switch it on in Settings → About → Features).
  - The last 200 things you copied, searchable; click one to copy it again.
  - Passwords from password managers, and text that looks like a password or key, are never kept.
  - It's stored encrypted on this Mac, and **Clear all** empties it.

## What BYTE can do in this version
- **Chat on your Mac** or with **BYTE Cloud** (invite only), with cards, on many kinds of models.
- **Research**, **writing and learning**, **speed and tuning**, **memory**, **your files and photos**, **documents**.
- **Mac control (Phase 9)**: Reminders, Calendar, Notes, Music, Shortcuts, Safari, system settings, Mail,
  Messages, selected text in any app, and clipboard history.

## Not in this version yet
Still to come in Phase 9: finding and organizing files, a Finder "Ask BYTE" action and a terminal helper. Replies
from the smallest models (under 2B) can be weak; BYTE catches a reply that just repeats the message and tries again.
Then automations (v0.10), voice and quick-ask windows (v0.11), Touch ID and polish (v0.12).
