# Phase 12 improvements — Polish for 1.0, and the first one-click update (v0.12.4)

**BYTE v0.12.4** is the first version that installs itself: if you have v0.12.3, open Settings → About, click
**Check for updates**, then **Install 0.12.4 and restart**. It's a polish pass on the way to 1.0. See all versions in [docs/VERSIONS.md](https://github.com/loganalexanderstarner-pixel/BYTE/blob/claude/new-session-tu1a5x/docs/VERSIONS.md).

## New in this version
- **A smoother first run:** the welcome guide suggests good-quality models first. Squeezed "low quality" versions
  and community remixes come later (they're all still there under "Show all").
- **Better model descriptions:** 23 models that only said things like "Ornith models." now say what they're good at.
- **Kids mode, safer:** uncensored, "obliterated" and other community remixes can't answer in kids mode (they stay
  available for grown-ups), and kids don't see Projects or private chats.
- **Starts lighter:** panels like Notes, Help, Settings and the board load the first time you open them, so BYTE has
  about 30% less to read when it starts.
- **Documents are marked Beta.** PDF and Word files are close to done; PowerPoint slides still need work, so look
  them over before you share them.
- **Connecting BYTE Cloud** links to the BYTE website and says where your key is: make an account, open Settings,
  scroll to the bottom.
- **A README with pictures** and an honest list of what BYTE can't do yet.

## What BYTE can do in this version
- **Chat on your Mac** or with **BYTE Cloud** (invite only), with cards, on many kinds of models.
- **Research**, **writing and learning**, **speed and tuning**, **memory**, **your files and photos**, **documents (beta)**.
- **Mac control** and **Mac upkeep**.
- **Everyday helpers**, **windows, keys and voice**, notes, mind maps and a brainstorm board.
- **Privacy:** an offline switch, a Touch ID lock, an activity log, kids mode, encrypted backups and erasing.
- **Looks:** 20 themes plus your own. **Updates:** one click, signed.
