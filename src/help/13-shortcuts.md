# Keyboard shortcuts

| Keys | What it does |
|---|---|
<!-- mac -->
| ⌥Space | Quick Ask from any app |
<!-- pc -->
| Ctrl+Alt+Space | Quick Ask from any app |
<!-- all -->
| ⌘K | Find chats, settings, modes and themes |
| ⌘N | New chat |
| ⌘, | Settings |
| ⌘\ | Show or hide the sidebar |
| ⌘? | This help |
<!-- mac -->
| ⌥⌘B | Send selected text in any app to BYTE |
<!-- win -->
| Ctrl+Alt+B | Send selected text in any app to BYTE |
<!-- all -->
| Enter / Shift+Enter | Send / new line |
| Hold Space | Dictate (empty message box) |
| Esc | Stop listening, close a panel |

<!-- mac -->
Change the global shortcuts in [Settings → General → Keyboard and menu bar](byte-setting:general).
<!-- pc -->
Change the global shortcuts in [Settings → General → Keyboard and system tray](byte-setting:general).
<!-- all -->
