# Keyboard shortcuts

| Keys | What it does |
|---|---|
| ⌥Space | Quick Ask from any app |
| ⌘K | Find chats, settings, modes and themes |
| ⌘N | New chat |
| ⌘, | Settings |
| ⌘\ | Show or hide the sidebar |
| ⌘? | This help |
| ⌥⌘B | Send selected text in any app to BYTE |
| Enter / Shift+Enter | Send / new line |
| Hold Space | Dictate (empty message box) |
| Esc | Stop listening, close a panel |

Change the global shortcuts in [Settings → About → Keyboard and menu bar](byte-setting:about).
