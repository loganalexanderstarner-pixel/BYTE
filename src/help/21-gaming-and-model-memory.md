# Gaming and where the model lives

A model can run in different places. Choose in [Settings → Models and speed](byte-setting:models) → **Where the model lives**:
- **Automatic:** the graphics card first, spilling to memory only when it helps.
- **Graphics memory only:** the fastest, but only models that fit on your card.
- **Graphics + system memory:** bigger models fit; the part in system memory runs slower.
- **Processor and system memory only:** slowest, but your graphics card stays free for games.

## While you play
1. Set where the model lives to the processor only if a game needs every bit of the card.
2. Connect [BYTE Cloud](help:cloud) and set **Answers from** to Automatic in [Settings → Voice and Hey BYTE](byte-setting:voice): during a full-screen game, spoken questions are answered from the cloud, there is no chime and spoken notices wait. Timers still ring.
3. In PC control, **Keep the game fast** keeps its helper model in system memory.

If a game still stutters, see [Troubleshooting](help:troubleshooting).
