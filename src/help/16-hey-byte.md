Say "Hey BYTE" from anywhere and BYTE answers out loud, like a speaker. It is **off until you turn it on**, and while it is on it listens through your microphone for the phrase (nothing is kept or sent anywhere until it hears the phrase).

## Set it up
1. Open [Settings → Voice and Hey BYTE](byte-setting:voice).
2. Make sure a **speech model** is installed (the voice section offers the download). Without it the switch stays grey.
3. Turn on **Listen for "Hey BYTE"**. Windows may ask to let BYTE use the microphone: allow it.
4. Say "Hey BYTE, what's the weather in Dover, Tennessee."

Try it: say "Hey BYTE, set a timer for ten minutes."

## What to expect
- **No window.** By default nothing pops up. BYTE answers out loud. Turn on **Show a window when I say "Hey BYTE"** if you would rather see it.
- **One breath works.** "Hey BYTE, what's the weather" is answered at once. You can also say just "Hey BYTE", wait for the chime, then ask.
- **Follow-ups.** After an answer BYTE keeps listening for a few seconds on the same microphone, so you can ask the next thing without the phrase. Say "thanks" to end it.
- **Wait until I'm done** (on by default): if you stop on a word like "and", "but" or "um", BYTE waits one more second and joins what you say next.
- **A listening pill and a chime.** A small pill shows while BYTE is listening, thinking or speaking. Choose the sound after "Hey BYTE" (system, soft or none), or hide the pill.
- **Talk key.** Set a key (Ctrl+Alt+Space is suggested) to talk to BYTE without the phrase. Pressing it while BYTE is talking stops it.
- **Open at login.** Turn on **Open BYTE at login** in [Settings → General](byte-setting:general) so it is ready as soon as you sign in.

## Where answers come from
In **Answers from**: **This PC** uses the model on this computer, **BYTE Cloud** uses the cloud, **Automatic** uses the cloud while a game runs or the graphics card is busy. The cloud choices need a [BYTE Cloud account](help:cloud). Cloud voices are made on the cloud; local voices on this PC.

## Quick Ask
**Ctrl+Alt+Space** opens a small ask box over any app. Type or speak.

## If it doesn't answer
See [Troubleshooting](help:troubleshooting): microphone access, the speech model, a game running, a call in progress.
