# Files, photos and the knowledge base

- **Attach** PDFs, Word, PowerPoint, Excel, text or code files, photos and recordings with the paperclip, or drop them on the window. Scanned PDFs and photos of text are read on your Mac.
- **Knowledge base:** add folders in [Settings → Knowledge base](byte-setting:knowledge). BYTE indexes them and answers "what do my files say about…" with the file and page cited.
- **Search by meaning** needs a small download, offered in the same tab.
- Your **notes** folder joins the knowledge base automatically when it's on.
