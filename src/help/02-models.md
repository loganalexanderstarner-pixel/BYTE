# Models and memory

BYTE runs open models (like Qwen3) on your Mac's GPU. Bigger models write better but need more memory.

- **Fits** labels show which models run well on this Mac. "Tight" models work if you close heavy apps.
- **Speed boost** (on by default) makes answers faster without changing them.
- You can **load a second model alongside** the main one and compare their answers.
- **Settings → Models and speed** shows live speed, memory and tuning.

<!-- mac -->
> **Tip:** If answers get slow, check Activity Monitor for apps using lots of memory, or pick a smaller model.
<!-- win -->
> **Tip:** If answers get slow, open Task Manager (Ctrl+Shift+Esc) to see which apps use lots of memory, or pick a smaller model. If a game is running, see [Gaming and games](help:interrupting-calls-games).
<!-- linux -->
> **Tip:** If answers get slow, check your system monitor for apps using lots of memory, or pick a smaller model.
