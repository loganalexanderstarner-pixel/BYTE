# Fix my writing in place, and "Ask BYTE" in Explorer

<!-- mac -->
**Fix my writing in place** works on the Mac too (turn it on in [Settings → Control and screen](byte-setting:control) under **Everyday helpers**). The Explorer right-click entry is part of the Windows app.
<!-- linux -->
These helpers aren't available on Linux yet, so there is nothing to set up here. See the other help articles for what works on Linux.
<!-- win -->
Both are under **Everyday helpers** in [Settings → Control and screen](byte-setting:control), **off until you turn them on**.

## Fix my writing in place
Select text in any app (an email, a chat, a document) and press the shortcut (Ctrl+Alt+W). A small popup next to the pointer offers:
- **Fix mistakes**, **Friendlier**, **More formal**, **More confident** and **Shorter**: BYTE writes a new version. You see it first; **Replace the selection** puts it back where it came from, and **Copy** keeps it on the clipboard. Nothing changes until you choose.
- **Explain this code**: what the selected code does, step by step, and any obvious bug.
- **Show the steps (maths)**: works through selected maths line by line.
- **Translate**: foreign text into English (and you can replace the selection with it).
The popup never takes the keyboard from the app you are in. BYTE copies the selection with Ctrl+C and puts your clipboard back, so it does not do this in a terminal or code editor, over a full-screen game, or in a window on your never-look-at list. Questions are answered on this computer unless you chose Cloud for the helpers.

## Ask BYTE in Explorer
Turn on **Explorer right-click: Ask BYTE** and every file gets an **Ask BYTE** entry in its right-click menu (for you only, no administrator needed). Choosing it opens the file attached in a new BYTE chat; type your question and send it when you like, nothing is sent by itself. Turning the switch off removes the entry. If BYTE was closed it starts first.

Windows does not let a program take files or text dropped on its tray icon, so that is not possible. Drop the file on the BYTE window instead (it attaches the same way).
